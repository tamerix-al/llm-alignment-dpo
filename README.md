# DPO Fine-tuning Experiments

Учебная работа по дообучению небольших авторегрессионных языковых моделей методом Direct Preference Optimization (DPO). Цель — сравнить ранжирование ответов и характеристики свободной генерации до и после обучения.

## Данные и постановка эксперимента

Использован датасет [Dahoas/full-hh-rlhf](https://huggingface.co/datasets/Dahoas/full-hh-rlhf) с полями `prompt`, `chosen`, `rejected`. После перемешивания (seed 42) и фильтрации пустых и длинных примеров отобраны 2 000 примеров для обучения и 100 для оценки из исходного train split. Для preference accuracy использованы первые 60 оценочных пар. Для каждой модели также сравнивались генерации на пяти одинаковых запросах до и после обучения.

DPO обучает модель повышать относительное предпочтение выбранных ответов по сравнению с отклонёнными, учитывая исходную модель. В работе использован `DPOTrainer` из Hugging Face TRL.

| Модель | Шаги | Learning rate |
| --- | ---: | ---: |
| `sshleifer/tiny-gpt2` | 80 | 1e-4 |
| `distilgpt2` | 120 | 5e-5 |
| `EleutherAI/pythia-70m-deduped` | 120 | 5e-5 |

Общие параметры: beta = 0.1, batch size = 2, gradient accumulation = 8, max length = 512, AdamW. Исходный запуск выполнен на Tesla T4 в Google Colab.

## Результаты

Preference accuracy — доля пар, в которых средняя логарифмическая вероятность токенов выбранного ответа выше, чем отклонённого. Mean margin — средняя разность этих вероятностей в логарифмической шкале.

| Модель | Accuracy до | Accuracy после | Margin до | Margin после |
| --- | ---: | ---: | ---: | ---: |
| Tiny GPT-2 | 58.33% | 48.33% | 0.000044 | 0.000144 |
| DistilGPT-2 | 56.67% | 51.67% | -0.040802 | -0.013195 |
| Pythia-70M | 46.67% | 48.33% | -0.140461 | -0.134548 |

Средний margin вырос у всех трёх моделей, но accuracy выросла только у Pythia-70M (на 1 из 60 пар). Для DistilGPT-2 снизилась доля повторов в свободных генерациях; для остальных двух моделей она выросла. Сохранённые генерации и таблицы доступны в [ноутбуке](homework_12.ipynb).

## Ограничения

- Результаты не подтверждают устойчивого улучшения качества ответов после DPO. Модели малы и не являются полноценными instruction-tuned ассистентами.
- Оценка выполнена на небольшой выборке при одном seed. Статистическая значимость не проверялась.
- Обрезание последовательностей и отдельная токенизация prompt могут смещать границу completion в функции оценки. Метрика использует средний log-probability токенов, а не reference-adjusted DPO reward.
- Длина, разнообразие слов и доля повторов описывают форму генерации, но не её полезность или корректность.
